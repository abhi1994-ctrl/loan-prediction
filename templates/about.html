ACADEMIC INTERNSHIP PROJECT

LoanIQ

AI-Based Loan Approval System · AI-powered decision support

OBJECTIVE

Study historical loan outcomes

LoanIQ demonstrates how a classification pipeline can preprocess applicant data, compare candidate models, and show an estimated outcome with clear limitations.

TECHNOLOGY

Built with practical tools

PythonFlaskPandasNumPyScikit-learnJoblibHTML · CSS · JavaScript
ML WORKFLOW

Preprocessing through evaluation

  1. Clean target and remove applicant ID.
  2. Impute missing values inside the model pipeline.
  3. One-hot encode categories; scale numeric values for Logistic Regression.
  4. Compare three classifiers on the same stratified holdout.
  5. Select by F1 score, using ROC-AUC to break ties.
RESPONSIBLE USE

Not a banking system

This academic prototype does not make credit decisions. Historical data can encode bias; model scores are not calibrated lending probabilities. Do not enter real applicant personal information. A qualified human must review any real-world decision.

Dataset

Kaggle Loan Prediction Problem Dataset. The labeled training CSV is used for model evaluation and fitting. The companion test CSV has no outcome labels and is not used to train the model.
